# Amazon Homepage Clone

A static front-end recreation of an Amazon-style shopping homepage built with HTML and CSS. The project focuses on page layout, navigation sections, product-category cards, and styling.

![Amazon homepage preview](amazone%20clone-1.PNG)

## Features

- Dark navigation bar with logo, delivery location, search field, account area, orders, and cart icon.
- Secondary navigation panel with shopping links.
- Hero banner with a promotional message.
- Product-category cards for clothing, personal care, furniture, electronics, beauty, pet care, toys, and fashion.
- Footer with grouped informational links.
- Font Awesome icons loaded from a CDN.

## Tech Stack

- **HTML5** – page structure and content.
- **CSS3** – layout, colors, spacing, and hover effects.
- **Font Awesome** – navigation and shopping icons.

## Run Locally

No build tools or backend are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/IslamBilal/amazon-clone1.git
   cd amazon-clone1
   ```
2. Open `index.html` in your browser.

You can also use the VS Code Live Server extension for local preview.

## Current Scope

This is a **static UI practice project**. The search field, account links, cart, and shopping links are visual interface elements; product search, authentication, checkout, and payment processing are not implemented.

## Possible Improvements

- Make the layout responsive for mobile and tablet screens.
- Add working category and navigation links.
- Implement product search and cart interactions with JavaScript.
- Improve accessibility with descriptive image text, labels, and keyboard navigation.
